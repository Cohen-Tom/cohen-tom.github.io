Les variables

En C++, les variables sont utilisées pour stocker des données. Chaque variable a un type qui détermine la nature des données qu'elle peut contenir. Les types de variables les plus courants en C++ sont les suivants:

Construction des variables en C++
Type Syntaxe Générale Autre Syntaxe Exemple Détail
Boolean Boolean "nomVariable"; Boolean "nomVariable" = value; Boolean maVariable = true; Prend la valeur true or false
Character char "nomVariable"; char "nomVariable" = value; char maVariable = 'A'; S'écrit avec des guillemets simples ' et peut être définie par sa valeur en ASCII
String string "nomVariable"; string "nomVariable" = value; string maVariable = "Chaine de caractères"; S'écrit avec des guillemets doubles "
Integer int "nomVariable"; int "nomVariable" = value; int maVariable = 10;
Float float "nomVariable"; float "nomVariable" = valuef; float maVariable = 3.14f;
Double double "nomVariable"; double "nomVariable" = value; double maVariable = 3.14159;
Double auto "nomVariable" = value; auto maVariable = 3.14159; Doit obligatoirement être définie lors de sa création

Il est important de choisir le type de variable approprié en fonction des données qu'on souhaite stocker. Par exemple, utilisez int pour les nombres entiers, double pour les nombres à virgule, boolean pour les valeurs true/false, char pour les caractères individuels, et string pour les chaînes de caractères. Il existe plusieurs sous-types de variable pour les entiers pour les types signed, notamment:

  • short : pour les nombres entiers de -32 768 à 32 767
  • int : pour les nombres entiers de -2 147 483 648 à 2 147 483 647
  • long : pour les nombres entiers de -9 223 372 036 854 775 808 à 9 223 372 036 854 775 807
Voici quelques exemples de déclaration et d'initialisation de variables en C++: 
int age = 25;
short number = 2;
double nb = 3.1543434;
bool isCPlusPlusFun = true;
char grade = 'A';
std::string name = "Jean";

Précision pour le type string :

Pour pouvoir utiliser le type string il faut rajouter 

#include <string>
dans le haut du fichier c++. Par exemple : 
#include <iostream>
#include <string>

int main() {
    std::string monPrenom = "Jean";
    std::cout << monPrenom << std::endl;

    return 0;
}
